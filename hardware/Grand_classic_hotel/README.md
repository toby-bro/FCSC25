# Grand classic hotel

[Link to the challenge](https://hackropole.fr/fr/challenges/hardware/fcsc2025-hardware-mfc-sector1-trace/)

Everyone knows of that hotel in which one can copy his badge or modify it and have access to all the rooms. Having a Mifare Classic card is already one step more protected let's see if it can hold us out.

We are provided with the trace that was generated by a proxmark eavesdropping on a key exchange between a key and a lock.
Not knowing what proxmark was, I searched it up and found [this page](https://github.com/RfidResearchGroup/proxmark3/blob/master/doc/trace_notes.md) that seemed to be what we were looking for. It even talks about dumping ISO 14443-A traces to wireshark for further packet analysis, which I did... But I didn't know that Mifare ISO 14443 had nothing to do with standard ISO 14443 A, or at least the protocol differs sufficiently for the trace to be badly analysed when using the `14a` option instead of what I found with after a quick RTFM where I realized the answer was in front of my eyes since the beginning...

```txt
[offline] pm3 --> trace list --help
[...]
trace list -t mf               -> interpret as MIFARE Classic and decrypt crypto1 stream
```

When we get this [analysed trace](./trace-analysed.txt) in which we are looking for anything interesting. We see that they are AUTH-A and AUTH-B packets and proxmark tells us that the key seems to be `FFFFFFFFFFFF`.

During the challenge I basically just did this, but [this pdf](https://arxiv.org/pdf/0803.2285) describing in more detail how these cards work was interesting lecture once the FCSC was over.

So we were lucky that the key was so weak that proxmark found it for us.

Then by reading the analysed dump we understand that there is at first different auths happening for different sectors with different reads of different blocks. We also learn that a mifare classic card has 1024 bytes of memory organized in 16 sectors of 4 blocks.

- Sector 0 (blocks 0 - 3) is for general info on the card so we will skip analyzing it.
- Sector 1 (blocks 4 - 7) seems promising enough as when converting the hex to ASCII we find `FCSC{dca41bafe48` in block 4, and block 5 and 6 also contain valid ASCII text encoded in hex.

With that, all that is left is to submit the flag.

Overall this was a fun challenge and a nice introduction to modern days RFID cards.
